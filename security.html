Platform Security.

How we use PostgreSQL isolation and Supabase infrastructure to guard your business data.

Core security manifest · May 2026

1. Multi-Tenant Database Isolation

LedgrPro runs on the Supabase PostgreSQL backend. Data privacy is enforced at the storage-engine level using strict Row Level Security (RLS). Every query is automatically scoped by the user's tenant_id, making it programmatically impossible to retrieve data from another tenant's console.

2. Encrypted Authentication & SSO

Access control is managed via Supabase Auth:

  • Zero plain-text: passwords are never transmitted or stored in readable form.
  • SSL hardened: fully encrypted HTTPS for every request prevents man-in-the-middle interception.
  • SSO options: enterprise clients can configure corporate single-sign-on.

3. Active Backups & Recovery

Supabase runs automated daily snapshots of transaction logs. In case of local data corruption, records can be restored from redundant disaster-recovery states.

4. Immutable Enterprise Audit Logs

Available to Enterprise subscribers, LedgrPro keeps a tamper-evident administrative audit log — track who created invoices, adjusted stock or changed price lists, to the exact timestamp.
