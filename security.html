Platform Security.

Discover how we leverage modern PostgreSQL isolation policies and Supabase infrastructure to guard your business.

Core Security Manifest | May 2026

1. Multi-Tenant Database Isolation

StockMate utilizes the **Supabase** open-source enterprise PostgreSQL backend engine. Data privacy is guaranteed physically at the storage engine level using strict Row Level Security (RLS) policies. Every query is automatically scoped by the user's unique `tenant_id`, making it programmatically impossible for any user to retrieve data from an unrelated distributor console.

2. Encrypted Authentication & SSO

Access Control is fully managed via industry-vetted **Supabase Auth** services:

  • Zero Plain-Text: Password strings are never transmitted or preserved in readable formatting.
  • SSL Hardened: Fully encrypted HTTPS pathways safeguard every query to prevent man-in-the-middle interception.
  • SSO Options: Enterprise clients can configure corporate single-sign-on directory integrations.

3. Active Backups & Recovery

Your accounting core stays stable. Supabase executes automated daily binary snapshots to secure transaction logs. In case of local client data corruption, records can be restored to redundant disaster recovery states rapidly.

4. Immutable Enterprise Audit Logs

Available exclusively to **Enterprise** subscribers, StockMate archives a cryptographically sound administrative audit log. Track who generated invoices, adjusted stock counts, or applied wholesale price list modifications at exact historical milliseconds.
